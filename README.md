# Dhaataa Homebrew tap

Homebrew casks for apps made by Dhaataa.

```bash
brew install dhaataalimited-hub/tap/brbuddy
```

| Cask | App |
|---|---|
| `brbuddy` | [BRBuddy](https://github.com/dhaataalimited-hub/brbuddy): keeps your Mac awake and guards the screen while your AI agent works |

Casks are updated with each release. Questions: hello@dhaataa.com
